# en Description in English:
🎟️ TicketBot is a simple and flexible bot for managing requests on your Discord server.

✅ One-click ticket creation
✅ Close confirmation
✅ Reason selection before closing a ticket
✅ Logging of closed tickets in a separate channel

Perfect for support, applications, and complaints.
